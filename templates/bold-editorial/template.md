# Bold Editorial 模板说明

## 视觉系统参数

| 参数 | 值 | 说明 |
|------|------|------|
| --mc-bg | #1a1a2e | 深蓝黑底色，沉稳厚重 |
| --mc-bg-alt | #16213e | 辅助背景色，层次感 |
| --mc-text | #f5f5f5 | 高对比正文色 |
| --mc-text-muted | #a0a0b0 | 说明/注释文本 |
| --mc-primary | #FFD700 | 金色标题强调 |
| --mc-accent | #FFC107 | 深金色分割线/辅助 |
| --mc-border | #2a2a4a | 边框/分割线 |
| --mc-font-primary | Georgia, serif | 衬线标题字体 |
| --mc-font-secondary | Inter, sans-serif | 无衬线正文字体 |
| --mc-heading-size | 3rem | 大标题尺寸 |
| --mc-body-size | 1.1rem | 正文尺寸 |
| --mc-spacing-lg | 2.5rem | 宽松间距，editorial 感 |

**风格关键词**: 衬线标题、金色强调、深色背景、大字号、宽松间距、观点鲜明

## 何时选择

- 观点/评测类内容，需要标题醒目、立场鲜明
- editorial 风格视频，文字驱动叙事
- bold 风格场景，强调视觉冲击力和文字张力
- 对比/比较类内容，左右分栏或大标题结构
- mood/氛围类内容，金色+深底营造高端质感

## 何时不选择

- 需要数据展示（图表、数字为主）——选用 data-visualization 模板
- 需要代码展示（技术教程、终端画面）——选用 dark-tech 模板
- 极简风格（克制留白、微交互）——选用 minimal-clean 模板
- 高密度信息排版（需要大量小字号内容）——间距过大不适合

## 推荐 content_type

- **text**: 纯文字观点、引用、金句——衬线标题天然适配
- **comparison**: 对比评测、左右分栏——大标题+金色分割线
- **mood**: 氛围渲染、情绪表达——深底+金色的戏剧张力
