# Dark Tech — 视觉模板说明

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `--mc-bg` | `#0a0a1a` | 主背景色（深黑蓝） |
| `--mc-bg-alt` | `#1a1a2e` | 辅助背景色（深紫灰） |
| `--mc-text` | `#e0e0e0` | 主文本色（亮灰） |
| `--mc-text-muted` | `#6b6b7b` | 辅助文本色（暗灰） |
| `--mc-primary` | `#00ff88` | 主强调色（荧光绿） |
| `--mc-accent` | `#00cc6a` | 辅助强调色（暗绿） |
| `--mc-border` | `#2a2a3a` | 边框/分割线色 |
| `--mc-font-primary` | `'Inter', sans-serif` | 主字体 |
| `--mc-font-secondary` | `'JetBrains Mono', monospace` | 辅助字体（代码/数据） |
| `--mc-heading-size` | `2.5rem` | 标题字号 |

| `--mc-enter-type` | `'from-hidden'` | 入场动画类型 |
| `--mc-exit-type` | `'to-hidden'` | 出场动画类型 |

## 风格描述

Dark Tech 是一种深色技术美学模板。以深黑蓝底色搭配荧光绿强调色，呈现赛博朋克与终端界面的视觉语言。字体选用 Inter 作为 UI 文本载体，JetBrains Mono 用于代码/数据展示，强化"技术密度"的观感。整体氛围冷静、精密、硬核，适合传递高密度技术信息或以科技感为核心的品牌表达。

典型视觉元素：
- 终端风格文本块与代码片段
- 网格线与数据流线条
- 荧光绿高亮标记与扫描线效果
- 高对比度文字与深色背景的硬切换

## 何时选择

- 主题涉及 AI / 编程 / 技术架构 / 系统设计
- 需要呈现 editorial-tech 风格的内容
- 视频承诺强调"技术密度"或"硬核知识"
- 目标受众为开发者、工程师或技术决策者
- 推荐 content_type: `text`、`mood`、`process`

## 何时不选择

- 需要温暖色调或人情味表达（如教育故事、生活场景）
- 手绘风格或插画驱动的内容
- 企业报告或正式商务场景（选择 minimal-clean）
- 内容以情感叙事为主而非技术说明
- 需要大量色彩变化或柔和渐变的视觉风格
