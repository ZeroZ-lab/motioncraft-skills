# Data Visualization 模板

## 视觉系统参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 主背景色 | `#0f172a` | Slate 900，深蓝灰底，数据面板质感 |
| 辅助背景色 | `#1e293b` | Slate 800，卡片/面板背景 |
| 主文本色 | `#e2e8f0` | Slate 200，高对比正文 |
| 辅助文本色 | `#94a3b8` | Slate 400，标签/注释/说明文字 |
| 主强调色 | `#3b82f6` | Blue 500，数据值/图表主色 |
| 辅助强调色 | `#60a5fa` | Blue 400，hover/次级数据色 |
| 边框色 | `#334155` | Slate 700，分割线/卡片边框 |
| 主字体 | Inter | 正文/UI 字体 |
| 辅助字体 | JetBrains Mono | 数字/代码/数据值字体（等宽对齐） |
| 标题字号 | 2rem | 数据标题/指标值大小 |
| 正文字号 | 1rem | 标签/说明文字大小 |
| 默认动画时长 | 0.8s | power1.out，数据出场适合平滑过渡 |
| 默认缓动 | power1.out | 数据动画偏理性，避免弹性夸张 |

## 何时选择

- 统计数据展示：百分比、增长指标、KPI 仪表盘
- 报告/金融：年度报告、季度数据、投资分析
- data-visualization 风格：图表、趋势线、热力图、排行榜
- Brief 信号匹配：`style: data-visualization`、`topic: stats/finance/report`

## 何时不选择

- 需要温暖色调：情感叙事、生活方式、人文关怀类视频
- 叙事驱动：故事线为主、数据为辅的视频（用 bold-editorial）
- 手绘风格：插画/漫画/涂鸦风格（需要完全自定义模板）
- 极简白底需求：企业白板汇报、科普教学（用 minimal-clean）

## 推荐 content_type

- **data**：数字指标、统计图表、趋势数据
- **concept**：概念图解、架构分层、逻辑关系
- **process**：流程步骤、时间线、pipeline 可视化
