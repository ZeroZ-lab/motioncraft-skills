# Minimal Clean 模板

## 视觉系统参数

| 参数 | 值 | 说明 |
|------|---|------|
| 主背景 | #ffffff | 纯白 |
| 交替背景 | #f5f5f5 | 极浅灰 |
| 主文字 | #1a1a1a | 近黑 |
| 辅助文字 | #6b7280 | 中灰 |
| 主色 | #2563eb | 蓝 600 |
| 强调色 | #1d4ed8 | 蓝 700 |
| 边框 | #e5e7eb | 浅灰 |
| 字体 | Inter | 单字体家族 |
| 标题字号 | 2.25rem | 紧凑有力 |
| 正文字号 | 1rem | 清晰易读 |
| 入场动效 | from-hidden | 从隐藏淡入 |
| 出场动效 | to-hidden | 淡出至隐藏 |
| 默认时长 | 0.6s | 克制不拖沓 |
| 默认缓动 | power2.out | 自然收束 |

美学关键词：白底、高对比、留白充足、克制动效、无装饰、单色系。

## 何时选择

- 教学 / 科普：信息密度适中，需要清晰传达知识点
- 企业演示：专业、干净、可信赖的形象
- Minimal 风格：品牌本身追求极简，或内容本身就是主角
- 文字驱动的内容：标题和正文是核心视觉元素

## 何时不选择

- 需要深色背景：暗色系内容、夜间主题、科技感氛围（用 dark-tech）
- 数据密集展示：大量图表、数字、对比（用 data-visualization）
- 强观点表达：需要视觉冲击力、情绪张力（用 bold-editorial）

## 推荐 content_type

- **text**：大段文字排版，标题-正文层级清晰
- **concept**：概念解释，配图辅助理解
- **comparison**：两者对比，左右分栏或前后切换
